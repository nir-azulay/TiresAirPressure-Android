# ניהול לחץ אוויר בצמיגים

אפליקציה לניטור וניהול לחץ אוויר בצמיגים באמצעות חיבור Bluetooth.

## מנגנון גרסאות אוטומטי

הפרויקט כולל מנגנון אוטומטי להגדלת מספר הגרסה בכל בנייה:

- מספר הגרסה מורכב מ-4 חלקים: `Major.Minor.Patch.Build`
- בכל בנייה, מספר ה-Build מוגדל אוטומטית
- מספרי הגרסה מנוהלים בקובץ `app/version.properties`
- כדי לשנות את מספרי ה-Major, Minor או Patch, יש לערוך את הקבועים בקובץ `app/build.gradle`:
  ```gradle
  def versionMajor = 1
  def versionMinor = 0
  def versionPatch = 0
  ```

### גישה למספר הגרסה בקוד

ניתן לגשת למספר הגרסה המלא בקוד באמצעות:

```kotlin
BuildConfig.VERSION_NAME // מחזיר את מחרוזת הגרסה המלאה (לדוגמה: "1.0.0.42")
```

### שימוש במנגנון הגרסאות

1. בכל בנייה, מספר הגרסה יוגדל אוטומטית
2. קובץ `version.properties` מכיל את מספר הבנייה הנוכחי
3. מספר הגרסה המלא מוצג באפליקציה ומשמש לזיהוי גרסאות שונות
